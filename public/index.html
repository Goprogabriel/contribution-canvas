How do I update my GitHub contribution graph?

There are two versions of Contribution Canvas. The hosted page is for designing. The downloaded local version is what safely creates and pushes commits to GitHub.

01Using the GitHub Pages websiteDesign only

Design and save your plan

  1. Open the canvas and draw your pattern or place pixel text.
  2. Use Export to download the plan as a JSON file.
  3. To publish the plan to GitHub, continue with the local steps.

Important: GitHub Pages cannot access your account and cannot push. This protects your token.

02Using the downloaded programCan push

Push once and update your profile

  1. Install GitHub CLI, then run gh auth login.
  2. Clone the project and start the local studio:
git clone https://github.com/Goprogabriel/contribution-canvas.git
cd contribution-canvas
npm start
  1. Import your JSON plan, choose a repository, run the safety check and load current activity.
  2. Run the dry-run, type the exact commit total, then choose Generate & push once.
  3. Open your GitHub profile later. GitHub can take up to 24 hours to show the contribution graph.

Nothing is pushed before your confirmation. The program uses one normal push and never force-pushes.
