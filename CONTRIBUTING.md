# Contributing

Thank you for improving Contribution Canvas.

## Development

```bash
git clone https://github.com/Goprogabriel/contribution-canvas.git
cd contribution-canvas
npm install
npm run verify
npm start
```

The project intentionally has no production dependencies. Use Node.js 20 or newer.

## Pull requests

Keep changes focused, add or update tests, avoid introducing browser-side secrets, and never add a force-push path. Run `npm run verify` before opening a pull request.

Use conventional commit prefixes such as `feat:`, `fix:`, `docs:`, `test:` and `chore:`.
